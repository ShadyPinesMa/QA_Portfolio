# **Python Selenium Automation Testing Project**

## **Project Overview**

This project demonstrates automated UI testing using Selenium WebDriver, Python, and Pytest.

The framework automates core user workflows (login, add items to basket, and checkout) and validates functionality using automated assertions.

## **Technologies Used**

- Python
- Selenium WebDriver
- Pytest
- EdgeDriver
- CSV

## **Automated Test Scenarios**

- User login
- Invalid login validation
- Add to cart
- Checkout flow
- Form validation

## **Framework Features**

- Pytest test execution
- Assertions and validations
- Reusable page objects
- Organized test structure
- Automated browser interaction

## **Included Artifacts**

- Automation framework source code
- Test plan
- Execution screenshots
- Test execution reports

## **How to Run Tests**

1. Clone repository
2. Create and activate a virtual environment

```
python -m venv .venv
```

Or if you're using Windows:

```
.venv\Scripts\activate
```

3. Install the dependencies

```
pip install -r requirements.txt
```
